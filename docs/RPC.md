# واجهة RPC المحلية

مغلقة افتراضياً. فعّلها من «المزيد ← التحكم عن بُعد». تستمع على `127.0.0.1:6800` (أو كل الواجهات إن سمحت بالشبكة المحلية). تعمل ما دام التطبيق مفتوحاً أو يُنزّل (قيود Android على العمل في الخلفية). **ليست متوافقة مع aria2.**

كل طلب يحتاج: `Authorization: Bearer <الرمز>` (من شاشة RPC؛ «رمز جديد» يُبطل القديم). الردود JSON.

| الطريقة | المسار | الوصف |
|---|---|---|
| GET | `/api/status` | `{"running":n,"speedBps":n,"held":null|"WIFI_ONLY"...}` |
| GET | `/api/tasks` | آخر 200 مهمة: `id`، `name`، `status`، `total`، `done` |
| POST | `/api/add?referer=<رابط مُرمَّز>` | الجسم أي نص؛ تُستخرج كل روابط http/https/ftp/sftp (حتى 500) وتُضاف بقواعد التنظيم. `200 {"added":n}` أو `422` إن لم توجد روابط |
| POST | `/api/pause/{id}` و`/api/resume/{id}` | `200 {"ok":true}` أو `404` |

حدود: جسم حتى 256 ك.ب (`413`)، 8 اتصالات متزامنة، بلا CORS.

```bash
curl -H "Authorization: Bearer $TOKEN" --data "https://example.org/file.zip" http://PHONE-IP:6800/api/add
```

إضافة متصفح للحاسوب: لم تُنشر بعد؛ أي أداة تستطيع إرسال الطلب أعلاه (مثلاً اختصار أو سكربت). الاقتران = نسخ الرمز يدوياً من الهاتف.
