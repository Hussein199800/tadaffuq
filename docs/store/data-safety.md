# Google Play — نموذج أمان البيانات (Data Safety)

| السؤال | الإجابة |
|---|---|
| هل يجمع التطبيق أو يشارك أي نوع من بيانات المستخدم؟ | **لا** |
| هل البيانات مشفّرة أثناء النقل؟ | نعم لكل اتصال HTTPS/FTPS/SFTP؛ روابط HTTP العادية يختارها المستخدم وتُعلَّم «غير مشفّر» |
| هل يمكن للمستخدم طلب حذف البيانات؟ | كل البيانات محلية؛ تُحذف بحذف التطبيق أو من داخله |

ملاحظات للمراجعة:
- **خدمة أمامية `dataSync`:** تنزيلات بدأها المستخدم وتظهر في إشعار دائم بإيقاف، مع معالجة حد Android 15 الزمني (`onTimeout`).
- **`RECEIVE_BOOT_COMPLETED`:** لاستئناف تنزيلات المستخدم بعد إعادة التشغيل عبر WorkManager.
- **BitTorrent:** يكشف عنوان IP للأقران ويرفع أجزاءً — مذكور للمستخدم قبل البدء ومحدود افتراضياً.
- **لا** صلاحية الوصول لكل الملفات، ولا `QUERY_ALL_PACKAGES`، ولا المنبهات الدقيقة.
- targetSdk 36، المكتبات الأصلية (libtorrent) محاذاة 16KB (تحقق `zipalign -c -P 16`).
