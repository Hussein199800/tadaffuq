# بطاقة المتجر — العربية

**الاسم:** تدفّق — مدير التنزيل
**الوصف القصير (80):** نزّل ملفاتك أسرع بتعدد الاتصالات واستئناف آمن، بلا إعلانات ولا تتبع.

**الوصف الكامل:**
تدفّق مدير تنزيل عربي يسرّع تنزيل الملفات وينظمها، ببساطة ووضوح.

• **أسرع:** حتى 32 اتصالاً للملف الواحد، وتقسيم ديناميكي يقتسم الجزء الأبطأ، وتحميل ذكي يضيف الاتصالات فقط حين تفيد.
• **استئناف آمن:** يكمل بعد انقطاع الشبكة أو إعادة تشغيل الهاتف، ولا يخلط نسختين مختلفتين من الملف أبداً.
• **بلاطة النسخ:** انسخ رابطاً من أي تطبيق واضغط بلاطة «تدفّق» في الإعدادات السريعة.
• **بروتوكولات:** HTTP وHTTPS وFTP وFTPS وSFTP وتورنت وMagnet، مع Proxy وSOCKS5.
• **تحكم كامل:** طابور وأولويات، حد سرعة لكل ملف وعام، Wi-Fi فقط، أثناء الشحن، حدود بيانات الجوال، نافذة زمنية ليلية.
• **متصفح خفيف:** تبويبات وتصفح خاص والتقاط روابط الملفات من الصفحة.
• **ملفات منظمة:** تصنيف تلقائي، قواعد تنظيم، فك ZIP و7Z وTAR، تحقق SHA-256، سلة محذوفات، ومجلد خاص مشفّر بالبصمة.
• **للمطورين:** إصدارات GitHub المناسبة لجهازك، ونماذج Hugging Face وGGUF المجزأة مع التحقق من البصمة.
• **طبيب التحميل:** يشرح سبب البطء أو الفشل بالعربية ويقترح الحل.
• **خصوصيتك أولاً:** لا حساب ولا إعلانات ولا تحليلات. كل شيء على جهازك.

عربي أولاً مع دعم الإنجليزية، فاتح وداكن وMaterial You.
