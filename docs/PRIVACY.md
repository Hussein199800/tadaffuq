# سياسة الخصوصية — تدفّق

**آخر تحديث:** 2026-11-25

تدفّق مدير تنزيل يعمل على جهازك. لا يجمع أي بيانات شخصية ولا يرسلها إلى المطوّر أو أي طرف ثالث.

- **لا حساب، لا إعلانات، لا تحليلات، لا متتبعات.**
- **الاتصالات الشبكية** تتم فقط مع الخوادم التي تطلب التنزيل منها أو تتصفحها، ومع واجهات GitHub وHugging Face حين تستعمل قسم المطورين، ومع أقران شبكة BitTorrent حين تضيف تورنتاً (وهو بطبيعته يكشف عنوان IP لهم ويرفع أجزاء الملف، ويوضّح التطبيق ذلك قبل البدء).
- **ما يبقى على جهازك فقط:** سجل التنزيلات والإعدادات والروابط المحفوظة والمفضلة وسجل التصفح والكوكيز وكلمات المرور (مشفّرة بـ Android Keystore) والملفات.
- **الحافظة:** تُقرأ فقط حين تضغط بلاطة «تدفّق» أو حين تفعّل «اقتراح الرابط المنسوخ» وتفتح التطبيق. لا قراءة في الخلفية.
- **النسخ الاحتياطي:** معطّل في السحابة. النسخ اليدوي ملف JSON تختار مكانه، بلا كلمات مرور أو رموز أو كوكيز.
- **واجهة RPC:** مغلقة افتراضياً، ومحلية، وتتطلب رمزاً سرياً.
- **الحذف:** إزالة التطبيق تحذف كل بياناته. ملفات المجلد الخاص المشفّرة لا يمكن استرجاعها بعد ذلك.

# Privacy Policy — Tadaffuq

**Last updated:** 2026-11-25

Tadaffuq is an on-device download manager. It does not collect or send any personal data to the developer or third parties.

- No account, no ads, no analytics, no trackers.
- Network connections go only to servers you download from or browse, to the GitHub and Hugging Face APIs when you use developer tools, and to BitTorrent peers when you add a torrent (which inherently exposes your IP address to them and uploads pieces; the app explains this before starting).
- History, settings, saved links, bookmarks, browsing history, cookies, passwords (encrypted with Android Keystore) and files stay on your device.
- The clipboard is read only when you tap the Tadaffuq tile, or when you enable "Suggest copied link" and open the app. Never in the background.
- Cloud backup is disabled. Manual backup is a JSON file you place yourself, without passwords, tokens or cookies.
- The RPC interface is off by default, local, and token-protected.
- Uninstalling removes all app data; encrypted vault files cannot be recovered afterwards.
