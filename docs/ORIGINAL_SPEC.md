# تدفّق | Tadaffuq — مدير تحميل عربي

## الهدف
بناء تطبيق Android أصلي لإدارة وتسريع تنزيل الملفات، يجمع أفضل أفكار Ghost Downloader 3 وIDM وADM و1DM وFDM وJDownloader، بهوية عربية مستقلة وروح Apple في البساطة والتفاعلية. لا تضف وظائف تنزيل الوسائط المتخصصة أو تشغيل الفيديو والصوت أو تحويلها أو ضغطها أو تحرير الصور. تعامل مع الملفات العامة بغض النظر عن امتدادها.

## محرك التحميل
- تحميل متعدد الاتصالات حتى 32 اتصالاً قابلاً للتخصيص وفق قدرات الخادم، وتقسيم ديناميكي وإعادة توزيع الأجزاء البطيئة.
- الكتابة المباشرة في مواضع الملف، وإعادة استخدام الاتصالات، واختيار عددها تلقائياً.
- تنزيلات متوازية، قوائم انتظار، أولويات، تحديد السرعة لكل مهمة وإجمالاً.
- إيقاف واستئناف وإعادة محاولة تلقائية بتأخير تدريجي، واستعادة المهام بعد انقطاع الشبكة أو إعادة تشغيل الجهاز ضمن قيود Android.
- حفظ تقدم الأجزاء بصورة دائمة، والتحقق من Range وETag وLast-Modified؛ عدم الاستئناف غير الآمن عند تغير الملف.
- تحديث الروابط المنتهية، ودعم المرايا واختيار الأسرع بعد التحقق من تطابق المحتوى.
- دعم الملفات الكبيرة، فحص المساحة، منع الكتابة فوق الملفات دون موافقة، والتحقق من SHA-256 وMD5 عند توفر بصمة مرجعية.
- اكتشاف التكرار بالرابط والاسم والحجم والبصمة، مع خيارات التجاوز أو الاستبدال أو إعادة التسمية.
- دعم HTTP/HTTPS وFTP/FTPS/SFTP وفق مكتبات موثوقة، وProxy وSOCKS5 والمصادقة وHeaders وCookies وReferer وUser-Agent، دون تعطيل TLS.
- وضع السرعة القصوى ووضع الإنترنت الضعيف ووضع توفير البيانات والبطارية.

## التقاط الروابط والمتصفح
- استقبال الروابط عبر المشاركة وفتح الروابط الخارجية، واقتراح الرابط المنسوخ عند السماح بذلك.
- معاينة اسم الملف وحجمه ونوعه ومصدره قبل التنزيل، وإمكانية تعديل الاسم والمجلد والإعدادات.
- لصق روابط متعددة واستيراد TXT وCSV واستخراج الروابط من النصوص وتوليد الروابط المتسلسلة بأنماط رقمية.
- تجميع التنزيلات في حزم، وتعديلها وإيقافها واستئنافها جماعياً.
- متصفح خفيف متعدد التبويبات، مفضلة وسجل وتصفح خاص وبحث داخل الصفحة ووضع سطح المكتب وإدارة الجلسات وحجب النوافذ المزعجة والمتتبعات اختيارياً.
- التقاط روابط الملفات العامة من الصفحات وفلترتها حسب الامتداد والحجم، دون استخراج مسارات الوسائط أو تجاوز الحماية.
- مركز روابط لحفظ الروابط وتنظيمها وتنزيلها لاحقاً.
- إمكانية استقبال الروابط من إضافة متصفح للحاسوب أو جهاز آخر عبر اقتران آمن، وواجهة RPC اختيارية محمية ومغلقة افتراضياً.

## التورنت
- دعم Torrent وMagnet، ومعاينة الملفات واختيار المطلوب وأولوية كل ملف.
- عرض Seeders وPeers وTrackers، ودعم DHT وPEX، وإدارة سرعة الرفع والتنزيل ونسبة المشاركة.
- إيقاف المشاركة وفق قواعد المستخدم، وإعادة فحص الأجزاء، وحفظ حالة الاستئناف وإدارة مسارات الحفظ.
- توضيح استهلاك البيانات والرفع للمستخدم قبل بدء المهمة.

## الجدولة والأتمتة
- جدولة المهام حسب التاريخ والوقت والشبكة، مع مراعاة قيود النظام وعدم الوعد بدقة زمنية غير متاحة.
- Wi-Fi فقط أو شبكات محددة، أثناء الشحن، والتوقف عند انخفاض البطارية أو المساحة أو ارتفاع الحرارة.
- حدود يومية وشهرية للبيانات، وإعدادات مستقلة لكل شبكة، ووضع ليلي.
- بدء المهمة التالية تلقائياً، وإجراءات بعد الاكتمال مثل التحقق من البصمة وفك الأرشيف ونقل الملف والإشعار.
- ملفات تعريف قابلة للتخصيص للمنزل والعمل والسفر والإنترنت المحدود.

## إدارة الملفات
- تصنيف تلقائي حسب النوع، ومجلدات مخصصة، ودعم الذاكرة الخارجية وUSB OTG عبر واجهات Android الرسمية.
- البحث والفرز والتحديد الجماعي وإعادة التسمية والنقل والنسخ والمشاركة والحذف.
- عرض معلومات الملفات وبصماتها، وفتحها بالتطبيقات الخارجية المناسبة.
- فك ZIP وRAR و7Z وإنشاء الأرشيفات بحسب المكتبات المدعومة، مع الحماية من Zip Slip والأرشيفات الضارة.
- اكتشاف الملفات المكررة والكبيرة والفارغة، وتنظيف المؤقتات وسلة محذوفات للملفات التي يديرها التطبيق.
- مجلد خاص بتشفير فعلي وحماية بالبصمة، ونسخ احتياطي واستعادة لسجل التنزيلات والإعدادات.

## قسم المطورين
- استعراض GitHub Releases واختيار الملفات المناسبة لمعمارية الجهاز.
- تنزيل ملفات Hugging Face ونماذج GGUF المجزأة مع دعم المصادقة الرسمية عند الحاجة.
- إدارة المرايا، وعرض تفاصيل الاتصالات والاستجابات، وتصدير سجلات تقنية منزوعة البيانات الحساسة.
- بنية إضافات مستقلة لتوسعة مصادر التحميل مستقبلاً.

## الذكاء والتقارير والتفاعلية
- طبيب التحميل: تشخيص بطء الخادم أو الشبكة أو التخزين أو عدم دعم الاستئناف، واقتراح حلول واضحة بالعربية.
- ضبط الاتصالات تلقائياً وفق الأداء والحرارة والبطارية، وتقدير واقعي للوقت المتبقي.
- عرض السرعة اللحظية والمتوسطة والقصوى، وحجم البيانات، وتقدم كل جزء، ورسم حي للسرعة والاتصالات.
- تقارير يومية وأسبوعية وشهرية وسنوية، واستهلاك Wi-Fi والبيانات، ونسبة نجاح المهام وتوزيع الملفات والمساحة، وتصدير CSV.
- مشهد حي اختياري يوضح تدفق البيانات من الخادم إلى الهاتف باستخدام القراءات الحقيقية.
- إشعارات حية مع الإيقاف والاستئناف، وإشعار موحد للمهام المتعددة، وWidget واختصارات التطبيق ولوحة الإعدادات السريعة.
- عدم اختلاق قراءات أو تسمية الخوارزميات التقليدية ذكاءً اصطناعياً.

## الهوية وتجربة الاستخدام
- الاسم المقترح: تدفّق | Tadaffuq. أزرق داكن #142B4A ونعناعي #34D6AE، وخلفية فاتحة #F5F7FA وداكنة #0D1117.
- التبويبات: الرئيسية، المتصفح، التنزيلات، الملفات، المزيد. الرئيسية تعرض ملخصاً حياً؛ والتنزيلات تعرض النشطة والمنتظرة والمكتملة والمتوقفة والفاشلة.
- العربية أساسية مع RTL حقيقي والإنجليزية اختيارية، وخط IBM Plex Sans Arabic أو بديل مناسب.
- روح Apple: عناوين كبيرة، تفاصيل رمادية، مساحات مريحة، أيقونات موحدة، بطاقات هادئة، Bottom Sheets، انتقالات ناعمة وتفاعل لمسي مدروس.
- وضع فاتح وداكن وتلقائي، وتخصيص الألوان والخط وترتيب التبويبات وطريقة عرض القوائم.
- دعم الشاشات المختلفة والأجهزة اللوحية وقارئات الشاشة ومناطق لمس مناسبة وحالات الفراغ والخطأ والتحميل والنجاح.
- واجهة بسيطة افتراضياً وإعدادات متقدمة اختيارية؛ لا تكدس الوظائف ولا تفرض خيارات غير ضرورية.

## البنية والأمان
- Kotlin، Jetpack Compose، Material 3 بتصميم مخصص، MVVM + Clean Architecture، Room، DataStore، Hilt، Coroutines وFlow، OkHttp، ومكتبة تورنت مناسبة مثل libtorrent عبر ربط متوافق.
- فصل محرك التحميل والمتصفح والتورنت والتخزين والجدولة والواجهات إلى وحدات مستقلة.
- استخدام Foreground Services وWorkManager وآليات نقل البيانات الحديثة حسب إصدار Android ونوع المهمة، وSAF وAndroid Keystore.
- استهداف Android 9 فأحدث حيث تسمح المكتبات، مع استهداف SDK حديث ومتطلبات النظام الحالية.
- لا تسجيل دخول إجباري ولا إعلانات ولا متتبعات. الوظائف المحلية تعمل دون إنترنت، والأذونات عند الحاجة فقط.
- حماية بيانات المصادقة والجلسات، وعدم تسجيل الأسرار، والتحذير من الملفات التنفيذية غير الموثوقة، وعدم الادعاء بوجود فحص فيروسات دون محرك فعلي.
- احترام صلاحيات الوصول وتراخيص المكتبات والمحتوى؛ لا تجاوز DRM أو المصادقة.

3. اختبر الملفات الكبيرة، انقطاع الشبكة، تغير الروابط، الخوادم دون Range، إعادة تشغيل الجهاز، التزامن، نقص المساحة والبطارية والحرارة.

6. وثّق ما اكتمل وما لم يكتمل والقيود التقنية، ولا تدّع نجاح اختبار لم تنفذه. اتخذ المبادرة في الإصلاح والتحسين دون حذف وظائف أساسية أو تغيير الهوية بلا مبرر.
